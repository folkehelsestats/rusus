## **Prompt: Generate YAML recoding specification with missing value detection and parsing rules**

### **Goal**

Generate a structured YAML configuration file for an R data-cleaning pipeline.
The YAML must define variables, types, labels, value labels, recoding rules, and missing-value handling.

***

### **Context**

I am working with survey data that needs to be standardized and cleaned in R.
The YAML file will drive automated recoding, type conversion, and labeling.

Each variable must follow this structure:

* `colnames`: exact variable names
* `keywords`: patterns for matching similar variables
* `type`: target R type
* `label`: variable description
* `value`: value labels for categorical variables
* `recode`: mapping from raw values to cleaned values
* `missing`: rules for detecting and converting missing values

***

### **Source**

You will use two inputs:

#### 1. R variable labels

```r
var_label(ssb) <- list(
  Kjonn = "IOs kjønn",
  Alder = "IOs alder",
  sluttdato = "Dato for utfyllinga",
  Yrkesstatus = "Yrkesaktiv?"
)
```

#### 2. CSV metadata

```
variable     class    n_unique    values
Kjonn        integer  2           1, 2
Alder        integer  64          33, 22, 45, 29
sluttdato    integer  64          29052025, 16062025
Yrkesstatus  integer  4           1, 2, 9, 8
YrkStat2     integer  11          NA, 1, 5, 4
```

***

### **Rules / Instructions**

#### 1. Variable mapping

* Match variables between R labels and CSV
* Use lowercase variable name as YAML key
* Populate:
  * `colnames` from variable name
  * `keywords` from variable name + common variants

***

#### 2. Type assignment (improved parsing)

* Use CSV `class` as base type
* Apply overrides:

| Pattern                                   | Rule                 |
| ----------------------------------------- | -------------------- |
| Name contains `dato`, `date`              | type = `date`        |
| Values look like `ddmmyyyy` or `yyyymmdd` | type = `date`        |
| Numeric with many unique values           | type = `integer`     |
| Few unique numeric values                 | treat as categorical |

***

#### 3. Value + recode logic

* If `n_unique > 10`:
  * `value: ~`
  * `recode: ~`

* If `n_unique ≤ 10`:
  * Treat as categorical
  * Define `value` using observed values (if labels not known, keep numeric)
  * Define `recode` mapping raw → clean values (identity mapping if no better info)

***

#### 4. ✅ Automatic missing-value detection (NEW)

Detect likely missing values using:

##### Common missing codes:

* `NA`, `"NA"`, `""`
* `8`, `9`, `99`, `999`
* negative values like `-1`

##### Rules:

* If variable is categorical (`n_unique ≤ 10`) and values include `8`, `9`, `99`:
  * Treat these as missing unless clearly valid categories
* If frequency suggests rare/high codes:
  * Assume missing

##### Output:

Add a `missing` field:

```yaml
missing:
  - NA
  - 9
  - 99
```

* Also ensure these are mapped to `NA` in `recode`:

```yaml
recode:
  "1": 1
  "2": 2
  "9": NA
```

***

#### 5. Date parsing rules (NEW)

For date-like variables:

* Detect formats like:
  * `29052025` → assume `ddmmyyyy`
  * `20250629` → assume `yyyymmdd`
* Set:
  * `type: date`
* Add note in label if needed:
  `"Dato for utfyllinga (parsed from numeric format)"`

Optional recode example:

```yaml
recode:
  "29052025": "2025-05-29"
```

***

#### 6. Label assignment

* Use R labels directly
* If missing, fallback to variable name

***

#### 7. Output formatting

* Valid YAML only
* Use `~` for null values
* Keep consistent indentation
* Do not include explanations

***

### **Expected Output Example**

```yaml
kjonn:
```
